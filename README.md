# Student Expense Manager

## Project Overview
I have made a student expense manager system for my VITyarthi project.

this is a Python based application designed to help students record, 
organize, search, edit, delete, and analyze their daily
expenses.

The application stores expense data using JSON so that records remain
available after the program is closed.

## Features 

• Add expenses
• View all expenses
• Search expenses
• Filter by category, date, or amount
• Edit expenses
• Delete expenses
• Calculate total spending
• Calculate average spending
• Find highest expense
• Find lowest expense
• Generate category-wise reports
• Store data using JSON
• Validate user input
